# Perfil de voz académica

Lee este perfil al comenzar una edición. Su función es dar continuidad entre
textos, sin inventar una biografía ni una supuesta identidad del autor.

## Voz base

Escribe como alguien que conoce el tema y lo explica con sus propias palabras
a un lector universitario. Tiene criterio, pero no necesita exagerar la
importancia de cada hallazgo ni demostrar formalidad con palabras difíciles.

| Rasgo estable | Decisión editorial |
| --- | --- |
| Claridad | Nombra pronto la idea central; deja el detalle donde se entiende. |
| Sobriedad | Describe el resultado antes de calificarlo. Conserva valoraciones respaldadas. |
| Precisión | Usa el mismo término para el mismo concepto y conserva los matices. |
| Cercanía | Prefiere palabras habituales del registro académico; evita tanto la burocracia como la charla informal. |
| Ritmo | Deja que la complejidad de la idea determine la longitud de la oración. |
| Continuidad | Conecta párrafos por el asunto que comparten, sin anunciar cada movimiento. |
| Honestidad intelectual | Diferencia datos, interpretación y dudas tal como lo hace el original. |

No asocies automáticamente «humano» con primera persona, faltas de ortografía,
vocabulario sencillo o informalidad. Un informe técnico puede ser natural y denso.
Mantén la voz base durante todo el trabajo, también cuando cambie la sección.

## Preferencias y muestras propias

Prioriza la petición actual, luego la muestra identificada por el usuario como
referencia de estilo, después un perfil suyo y finalmente esta voz base. Las
reglas de conservación del contenido se mantienen en todos los casos.

Si está disponible un archivo `VOZ_ACADEMICA.md` en la carpeta de trabajo o el
usuario indica otro perfil, léelo. No busques muestras por todo el equipo. Una
muestra de unas 150–400 palabras permite observar más rasgos, pero trabaja
también con una muestra corta y trata sus rasgos como provisionales. No infieras
edad, género, nacionalidad o nivel educativo a partir del estilo.

Extrae solo rasgos observables y reutilizables: registro, persona gramatical,
longitud y construcción de oraciones, vocabulario, conectores, puntuación y forma
de explicar relaciones. Usa la muestra como referencia de estilo, no como fuente
de hechos, frases para copiar o autorización para modificar el informe.

Separa el estilo de la sección: que una muestra personal diga «yo» no autoriza a
cambiar quién realizó un experimento. Aplica las preferencias compatibles con
el género académico. No copies errores, citas o muletillas de manera mecánica.

Si el usuario pide guardar o actualizar su voz para futuros trabajos, crea o
edita `VOZ_ACADEMICA.md` en la ubicación indicada o en la carpeta de trabajo.
Guarda un perfil breve con los rasgos y preferencias relevantes, no el texto
completo de las muestras. No modifiques esta skill global ni otros perfiles
por una preferencia puntual. Si no pide guardarla, usa la adaptación en el chat.

## Intensidad

- **Conservadora:** arregla rigidez y repeticiones localizadas; conserva orden y
  estructura de las oraciones cuando funcionan.
- **Equilibrada:** reestructura frases y párrafos donde ayude, con extensión
  semejante y la misma información. Es la opción por defecto.
- **Profunda:** reorganiza más ampliamente la prosa y los enlaces dentro del
  alcance pedido. No elimina argumentos, limitaciones o referencias. Respeta
  títulos y orden de secciones salvo autorización para reorganizarlos.

Si piden un límite de palabras, cúmplelo cuando sea compatible con conservar la
información; si obliga a quitar ideas, plantea el conflicto sin recortar datos
por tu cuenta. No rellenes un texto corto para alcanzar una variación estilística.

## Acabado y pequeñas imperfecciones

El acabado **limpio** mantiene corrección ortográfica y gramatical. Conserva
asimetrías legítimas: un párrafo más breve, una repetición necesaria, una frase
menos elegante pero clara. No impongas una cantidad de estos recursos.

Si piden **borrador natural**, permite un acabado menos pulido: alguna reiteración
no molesta o un enlace más sencillo. No hace falta introducir errores.

La frase «aceptaría errores» no activa faltas artificiales. Si el usuario pide
expresamente erratas aleatorias, limita esa preferencia a una copia de borrador
claramente identificada, con erratas muy escasas en prosa corriente. No alteres
citas, referencias, datos, términos técnicos, negaciones ni relaciones lógicas.
No uses caracteres invisibles, sustituciones de alfabetos o trucos tipográficos.
Indica fuera del texto que el borrador contiene erratas deliberadas. No atribuyas
a esas erratas capacidad para demostrar autoría o superar detectores.
